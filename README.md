# vote-sys

Сервис анонимных голосований под нагрузку ТВ-эфира: ~100 млн зрителей, окно ~60 секунд.

- Обоснование архитектуры и технологий — **[architecture.md](./architecture.md)**
- Исходное ТЗ — [task.md](./task.md)
- Артефакты работы с ИИ — [ai/](./ai/)

> **Статус:** скелет. Инфраструктура (compose, nginx, миграции) готова, Go-пакеты —
> сигнатуры со ссылками на разделы `architecture.md`. Раздел «Запуск» ниже
> заполняется по мере реализации.

## Структура

```
cmd/api          точка входа сервиса
cmd/loadgen      нагрузочный генератор с профилем ТВ-эфира

internal/
  httpapi        HTTP-слой: голос, минт токена, админка
  poll           доменная модель, Postgres-хранилище, процессный кэш
  vote           счётчики (padded atomic) и батчер
  dedup          SET NX EX — узкое место системы
  breaker        circuit breaker для fail-open по Redis
  token          HMAC-токен голосующего
  results        снапшот Redis → память → Postgres
  platform       пулы соединений, graceful shutdown
  config         конфигурация из окружения

deploy/nginx     rate limiting, кэш результатов, роутинг
migrations       схема Postgres
web              лендинг зрителя и админка
```

## Запуск

```sh
cp .env.example .env
make deps
make up
```

Стенд поднимает nginx перед тремя инстансами, Redis и Postgres — топология
повторяет продовую в миниатюре, чтобы дедуп, шардирование счётчиков и
идемпотентный upsert проверялись в тех же условиях, в которых работают в проде.

`make help` — список остальных целей.
